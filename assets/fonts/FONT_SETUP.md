# Font Setup

This workflow was validated with user-provided NotoSansSC files. Do **not** commit or publish these font files unless you own the necessary redistribution rights.

For local rendering, place licensed or permitted copies at:

```text
assets/fonts/NotoSansSC-Regular.ttf
assets/fonts/NotoSansSC-SemiBold.ttf
assets/fonts/NotoSansSC-Bold.ttf
```

The HTML template should reference these local paths. If you use another font, document the substitution because Chinese glyph width and line wrapping can alter the blackboard safe layout. Exclude all font files from delivery ZIP packages by default.
